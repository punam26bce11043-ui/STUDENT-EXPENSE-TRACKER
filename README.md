# STUDENT-EXPENSE-TRACKER
A Python-based Student Expense Tracker for managing and analyzing daily expenses.

## 1. Project Overview

Student Expense Tracker is a Python-based application designed to help
college students record, manage, and analyze their daily expenses.

The system allows users to maintain their expense records, monitor their
budget, and understand their spending patterns.
---

## 2. Features

- Add a new expense
- View all expenses
- Delete an expense
- Categorize expenses
- View category-wise spending
- Set and analyze monthly budget
- Calculate total spending
- Identify highest spending category
- Generate an expense report
- Validate user input
---

## 3. Technologies Used

- Python
- CSV File Storage
- VS Code
- GitHub
