# Project Statement

## Project Title
Student Expense Tracker

## Problem Statement
College students often find it difficult to keep track of their
daily expenses. This project provides a simple system to record,
categorize, and analyze student expenses.

## Scope
The system allows students to add, view, and delete expenses,
manage their budget, and analyze their spending.

## Target Users
College students who want to manage and monitor their personal expenses.

## High-Level Features
- Add expenses
- View expenses
- Delete expenses
- Category-wise expense analysis
- Monthly budget analysis
- Spending analysis
- Highest spending category
- Generate expense report

## Technologies Used
- Python
- CSV File Storage
- GitHub
